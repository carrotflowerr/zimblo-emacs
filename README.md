# Descriptions

## Useful
* buffer-wipe.el
Kill all buffers.

* jump-middle.el
Go to the middle of the line. Based on characters.

* note.el
Super simple note script

* zimblo-find-char.el
Super simple rewrite of the vim f command. Code based off of
evil-jump-to-char.
